셀메이트 기본창고 재고 대조

셀메이트 가용재고(AT열) = cafe24 + 컬리 + W컨셉 + 그로잉세일즈 본사 — 파일 5개를 각 칸에 올리면 바로 대조합니다.

쉼표로 구분 · 셀메이트·판매처 상품명에 들어가면 양쪽 모두 대조에서 뺍니다
전체 대조표0 불일치 재고0 매핑 검토0

차이 = 셀메이트 가용재고 − 판매처 합계. 차이가 클수록 위에 놓입니다. 적색 행이 등식이 맞지 않는 옵션입니다.

사유 확인된 불일치

사유를 적어 둔 옵션은 불일치 건수에서 빠지고 여기에 모입니다. 다음 파일에서 차이 수량이 달라지면 다시 위 목록으로 올라갑니다.

셀메이트에 없는 판매처 옵션

판매처에는 재고가 있는데 셀메이트 기본창고 옵션과 연결되지 않은 행입니다. 등식에 포함되지 않으므로 매핑 검토 탭에서 연결하거나 셀메이트에 옵션을 등록하세요.

팀 전체에 반영하려면 내려받은 mapping.json을 깃허브 저장소에 덮어써 올리세요(Add file → Upload files). 다음부터 누가 열어도 같은 매핑이 적용됩니다.

저장된 매핑이 먼저 적용됩니다: 수동 지정 → 공유 매핑표(mapping.json) → 자동 누적. 없을 때만 자동 규칙: ① 바코드·품목코드 ② cafe24 품목코드를 그로잉 파일로 연결 ③ 한글 상품명(셀메이트 상품메모4) ④ 영문 상품명+컬러+사이즈(한글은 용어집으로 영문 변환) ⑤ 컬러 부분일치·철자 유사도 = 추정. 오른쪽 칸에서 셀메이트 옵션을 지정하면 바코드 기준으로 저장되어, 다른 날 다른 파일을 올려도 그대로 연결됩니다.

# 셀메이트 기본창고 재고 대조 대시보드

셀메이트 가용재고(AT열) = cafe24 + 컬리 + W컨셉 + 그로잉세일즈(본사) 등식이 맞지 않는 옵션을 찾는 웹 도구입니다.

## 사용 방법
1. 페이지를 열고 상단 칸 5개에 판매처 파일을 올립니다 (또는 "파일 한꺼번에 올리기").
2. **전체 대조표** — 옵션별 판매처 수량·합계·차이, 불일치 행 빨간색 표시
3. **불일치 재고** — 맞지 않는 옵션만, 원인 → 조치 / 사유 메모
4. **매핑 검토** — 추정·미매핑 행을 셀메이트 옵션에 직접 연결

## 매핑 누적 (다시 매핑하지 않기)
- 판매처 행은 **판매처 키**(cafe24 품목코드 · 컬리 옵션번호 · W컨셉 상품코드|옵션1 · 그로잉 품목코드)로, 셀메이트는 **바코드**로 기억합니다. 파일 순서·날짜가 달라도 같은 상품에 연결됩니다.
- 적용 순서: 수동 지정 → 공유 매핑표(`mapping.json`) → 자동 누적 → 자동 규칙
- `mapping.json` = 팀 공유 매핑표. 매핑 검토 탭의 **mapping.json 내려받기**로 받은 파일을 이 저장소에 덮어써 올리면(Add file → Upload files) 모든 팀원에게 적용됩니다.
- `b: "제외"`는 대조 제외, `r: 1`은 추정 매핑(확인 필요). 엑셀 대조표의 매핑표와 같은 키를 씁니다(엑셀 매핑표용 복사 버튼).

## 데이터 보안
올린 파일은 브라우저 안에서만 처리되며 어떤 서버로도 전송되지 않습니다.
수동 매핑·사유 메모·제외 키워드는 각 사용자의 브라우저(localStorage)에 저장됩니다.

## 배포 (GitHub Pages)
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/(root)` → Save.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
